# CodePath CS | Student Learning Hub

A peer-to-peer Computer Science learning hub created by students, for students. Master programming, algorithms, web development, and more through engaging lessons and collaborative study groups.

## Project Vision

CodePath CS was built with the mission to democratize computer science education. We believe that student-led learning is the most effective way to grasp complex engineering concepts. This platform serves as a central hub for FBLA students and aspiring developers to share knowledge and build together.

## Features

- **Interactive Lessons**: Hands-on coding tutorials.
- **Peer Tutoring**: Schedule sessions with experienced student mentors.
- **Resource Library**: Curated list of docs, cheat sheets, and videos.
